## 💻 Tech Stack & Features

This website is designed with a premium, sleek dark-themed aesthetic featuring micro-animations, glassmorphism, and responsive layouts.

*   **Framework**: [Vite](https://vite.dev/) + [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
*   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
*   **Components & Icons**: [Lucide React](https://lucide.dev/), [Shadcn UI](https://ui.shadcn.com/)
*   **Animations**: [Motion](https://motion.dev/) for smooth transitions

## 🚀 Getting Started Locally

To run this portfolio project on your local machine:

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/Ashyrie/atorreswebsite.git
    cd atorreswebsite
    ```

2.  **Install dependencies**:
    ```bash
    npm install
    ```

3.  **Run the local development server**:
    ```bash
    npm run dev
    ```

4.  **Build the project**:
    ```bash
    npm run build
    ```

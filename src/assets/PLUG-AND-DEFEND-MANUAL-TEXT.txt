How 	to 	Download 	& 	Verify 	Evidence
Download 	Process
Step 	1: 	Click 	"Download 	All 	(Signed)" 	button
This 	creates 	a 	ZIP 	bundle 	with 	all 	evidence 	files, 	GPG 	signatures, 	and 	verification 	instructions.
Step 	2: 	Download 	the 	ZIP 	file
You'll 	receive 	a 	file 	named 	scan_[ID]_evidence_signed_[TIMESTAMP].zip 	containing:
 	All 	evidence 	files 	(JSON, 	PCAP, 	logs, 	etc.)
 	GPG 	signature 	(.sig) 	for 	each 	file
 	README.txt 	- 	Complete 	verification 	instructions
Step 	3: 	Extract 	the 	ZIP 	file
Extract 	all 	files 	to 	a 	folder 	on 	your 	computer.
Step 	4: 	Verify 	signatures
Follow 	the 	instructions 	in 	README.txt 	to 	verify 	each 	file's 	authenticity 	using 	GPG.
Verification 	of 	Evidence 	files 	using 	GPG4WIN 	(Kleopatra)
Quick 	Verification 	(Windows):
1. 	Install 	Gpg4win
2. 	Download 	the 	PND 	public 	key 	from 	Audit 	Logs 	page
3. 	Import 	key 	in 	Kleopatra 	(The 	public 	key 	in 	.asc 	file 	format)
4. 	Verify 	each 	.sig 	file 	using 	the 	Public 	Key
5. 	Take 	note 	that 	the 	file 	that 	needs 	to 	be 	verified 	is 	the 	sig 	files 	partnered 	with 	each
files 	inside 	the 	folder 	of 	the 	extracted 	evidence 	.zip 	file
(example: 	pcap.log 	= 	original 	file, 	pcap.log.sig 	= 	is 	what 	needs 	to 	be 	verified)
It 	will 	then 	tell 	that 	the 	file 	is 	verified 	by 	“PNDSystem” 	meaning 	the 	original 	files
hasn’t 	been 	modified, 	ensuring 	file 	integrity.
